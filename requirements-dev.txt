# Dev/test dependencies. Enough to run `pytest tests/` on a laptop with no GPU.

# torch, transformers and huggingface_hub are needed by `test_batch_engine.py`: the cache
# gather is tensor indexing, so it cannot be stubbed, and `strands_decider.batch_engine`
# imports through `infer` -> `modeling`. CPU wheels are fine; no GPU is touched. Without
# them that module `importorskip`s itself and 17 tests silently pass as a skip, which is
# worse than failing -- the gather is the part that, if wrong, answers one caller's
# question from another caller's state.
# httpx is imported at module scope by `tools/loadsweep_triton.py`, which
# `test_deploy.py::test_entry_point_parser_builds` imports to prove its argparse parser
# assembles. It used to arrive transitively via huggingface_hub and so was never declared.
# That stopped being true: hub 1.33 depends on `httpx<1`, hub 2.2 depends on `httpx2<3` --
# a DIFFERENT distribution -- so once the resolver moved to 2.x the import vanished and the
# test failed on a file nobody had touched. Declared directly, because the tool really does
# need it and a transitive dependency is not a promise.
